Trabalhando com Theme em Flutter

Consistência e Escalabilidade no Design da sua Aplicação

1. Introdução ao Theme

O Theme é o sistema de estilos do Flutter, responsável por definir a aparência global dos componentes visuais da aplicação. Ele permite configurar cores, tipografia, formas e outros detalhes de design em um só lugar.

Por que usar?

  • Mantém consistência visual entre telas.
  • Facilita mudanças rápidas de identidade visual.
  • Evita repetição de estilos em cada widget.
import 'package:flutter/material.dart';

void main() {
  runApp(MyApp());
}

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      // Define um tema simples com a cor primária azul.
      theme: ThemeData(primarySwatch: Colors.blue),
      home: Scaffold(
        appBar: AppBar(title: Text('Meu App')),
        body: Center(child: Text('Olá, Flutter!')),
      ),
    );
  }
}

2. O Conceito de ThemeData

A classe ThemeData concentra todas as configurações do tema. Ela afeta todos os widgets que seguem as diretrizes do Material Design (como AppBar, TextButton, FloatingActionButton).

Principais propriedades:

  • colorScheme: Define o conjunto de cores primárias e secundárias.
  • textTheme: Controla fontes e tamanhos de texto.
  • iconTheme: Controla a aparência dos ícones.
  • elevatedButtonTheme: Define o estilo de botões elevados.
MaterialApp(
  theme: ThemeData(
    // Define a cor primária e de destaque.
    primaryColor: Colors.deepPurple,
    // Define os estilos de texto padrão para a aplicação.
    textTheme: TextTheme(
      bodyLarge: TextStyle(fontSize: 18, color: Colors.black87),
      titleLarge: TextStyle(fontWeight: FontWeight.bold, fontSize: 24),
    ),
    // Define um estilo padrão para todos os FloatingActionButtons.
    floatingActionButtonTheme: FloatingActionButtonThemeData(
      backgroundColor: Colors.deepPurple,
    ),
  ),
  // ...
);

3. Estrutura Básica

O tema é aplicado no widget raiz da aplicação, geralmente o MaterialApp.

  • primarySwatch: Define uma paleta de tons a partir de uma cor principal. É uma forma rápida de ter um esquema de cores coeso.
  • brightness: Controla o contraste geral (claro ou escuro), afetando cores de fundo e de texto padrão.
MaterialApp(
  title: 'Tema Básico',
  theme: ThemeData(
    // Gera uma paleta de cores a partir do azul.
    primarySwatch: Colors.blue,
    // Define que o tema é claro (fundo branco, texto preto).
    brightness: Brightness.light, 
    fontFamily: 'Roboto', // Define uma fonte padrão para o app.
  ),
  home: HomeScreen(),
);

4. Dark Theme

O Flutter facilita a implementação de um modo escuro. Basta definir os temas claro e escuro e o modo de exibição.

  • theme: Define o tema claro (padrão).
  • darkTheme: Define o tema escuro.
  • themeMode: Controla qual tema usar. ThemeMode.system usa a preferência do sistema operacional do usuário.
MaterialApp(
  // Tema para o modo claro.
  theme: ThemeData(
    brightness: Brightness.light,
    primarySwatch: Colors.indigo,
  ),
  // Tema para o modo escuro.
  darkTheme: ThemeData(
    brightness: Brightness.dark,
    primarySwatch: Colors.teal,
  ),
  // Usa a configuração do sistema para decidir entre claro e escuro.
  themeMode: ThemeMode.system, 
  home: HomeScreen(),
);

5. Tema Customizado

Você pode personalizar completamente o visual da aplicação configurando as propriedades do ThemeData.

Dica: ColorScheme.fromSeed() gera automaticamente um conjunto harmonioso de cores a partir de uma cor base, o que é ideal para o Material 3.

ThemeData customTheme = ThemeData(
  // Ativa o design do Material 3.
  useMaterial3: true,
  
  // Gera um esquema de cores a partir de uma cor "semente".
  colorScheme: ColorScheme.fromSeed(seedColor: Colors.teal),
  
  // Define um estilo padrão para todos os botões elevados.
  elevatedButtonTheme: ElevatedButtonThemeData(
    style: ElevatedButton.styleFrom(
      backgroundColor: Colors.teal, // Cor de fundo
      foregroundColor: Colors.white, // Cor do texto
      shape: RoundedRectangleBorder(
        borderRadius: BorderRadius.circular(12),
      ),
    ),
  ),
  
  // Personaliza a aparência da AppBar.
  appBarTheme: AppBarTheme(
    backgroundColor: Colors.teal,
    foregroundColor: Colors.white,
    elevation: 4,
  ),
);

6. Acessando o Tema no Código

Para usar propriedades do tema global em seus widgets, utilize Theme.of(context). Isso busca o ThemeData mais próximo na árvore de widgets.

Essa abordagem evita "hardcoding" (fixar valores no código), tornando o design mais adaptável a mudanças e ao modo escuro.

class MyWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    // Acessa o tema atual.
    final theme = Theme.of(context);

    return Column(
      children: [
        // Usa o estilo de texto 'titleLarge' definido no tema.
        Text(
          'Título da Seção',
          style: theme.textTheme.titleLarge,
        ),
        // Usa a cor primária do esquema de cores do tema.
        Container(
          width: 100,
          height: 100,
          color: theme.colorScheme.primary,
        ),
      ],
    );
  }
}

7. Themes Locais

Você pode criar temas específicos para uma parte da tela envolvendo um grupo de widgets com o widget Theme.

Isso é útil para destacar uma seção com um estilo exclusivo, sem alterar o tema global da aplicação.

// Widget que usa o tema global.
Card(
  child: Text('Card com tema padrão'),
);

// Envolve um widget com um Theme para aplicar um estilo local.
Theme(
  // Pega o tema atual e sobrescreve apenas a cor primária.
  data: Theme.of(context).copyWith(
    colorScheme: ColorScheme.fromSwatch(primarySwatch: Colors.orange),
  ),
  child: ElevatedButton(
    onPressed: () {},
    child: Text('Botão Laranja'),
  ),
);

8. Material 3 e Color Schemes

O Flutter suporta o Material Design 3, que traz um sistema de design mais moderno e adaptativo.

  • Paletas dinâmicas (dynamic color): No Android 12+, as cores do app podem se basear no papel de parede do usuário.
  • Novos componentes: Widgets com estilos atualizados e mais flexíveis.
  • Foco em ColorScheme: A propriedade colorScheme se torna a principal forma de definir cores, garantindo temas mais coerentes e acessíveis.
MaterialApp(
  theme: ThemeData(
    // Ativa o Material 3.
    useMaterial3: true,
    
    // Define um esquema de cores a partir de uma cor semente e brilho.
    colorScheme: ColorScheme.fromSeed(
      seedColor: Colors.indigo,
      brightness: Brightness.light,
    ),
  ),
  // ...
);

9. Estratégias para Projetos Maiores

Em projetos maiores, recomenda-se modularizar o tema em arquivos separados para melhor organização e manutenção.

lib/
  ├─ theme/
  │   ├─ app_theme.dart
  │   ├─ light_theme.dart
  │   └─ dark_theme.dart
// lib/theme/app_theme.dart

import 'package:flutter/material.dart';

class AppTheme {
  static final ThemeData light = ThemeData(
    useMaterial3: true,
    colorScheme: ColorScheme.fromSeed(seedColor: Colors.blue),
    brightness: Brightness.light,
  );

  static final ThemeData dark = ThemeData(
    useMaterial3: true,
    colorScheme: ColorScheme.fromSeed(
        seedColor: Colors.blue, brightness: Brightness.dark),
    brightness: Brightness.dark,
  );
}

// main.dart
// import 'package:my_app/theme/app_theme.dart';

MaterialApp(
  theme: AppTheme.light,
  darkTheme: AppTheme.dark,
  themeMode: ThemeMode.system, // ou gerenciado por um state manager
);
