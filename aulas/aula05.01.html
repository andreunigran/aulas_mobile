Guia do Widget Dismissible no Flutter

Dominando interações de deslize em suas listas.

1. O que é o Dismissible?

Um widget inovador que permite remover ou interagir com itens por gestos de deslize. Suas principais características são:

  • Muito usado em listas dinâmicas, como caixas de e-mail, listas de tarefas e apps de mensagens.
  • Permite customização completa do comportamento e visual durante o deslize.
  • Trabalha junto com ListView, GridView ou qualquer widget que gere múltiplos elementos.

2. Estrutura básica

Dismissible(
  key: Key(item.id), // Identificador único, obrigatório
  onDismissed: (direction) { 
    // Função chamada quando o item é removido
  },
  background: Container(color: Colors.red), // Área exibida ao deslizar
  child: ListTile(title: Text(item.nome)),  // Conteúdo principal
)

Comentários importantes:

  • key: É crucial, pois identifica cada item da lista. Sem isso, o Flutter não sabe qual item foi removido.
  • onDismissed: Executa a lógica (ex: deletar da lista, banco de dados, mostrar aviso).
  • background: Mostra o que aparece quando o usuário arrasta (ícone de lixeira, cor, etc.).
  • child: O item em si (normalmente ListTile, mas pode ser qualquer widget).

3. Direções de deslize

Você pode controlar para qual lado o item pode ser deslizado:

  • DismissDirection.startToEnd: Da esquerda para a direita.
  • DismissDirection.endToStart: Da direita para a esquerda.
  • DismissDirection.horizontal: Aceita os dois lados.
  • DismissDirection.vertical: Aceita deslizar para cima ou para baixo.
  • DismissDirection.up e DismissDirection.down: Direção única vertical.

💡 Estratégia: Usar direções diferentes para ações distintas (ex: arrastar para direita = arquivar, esquerda = deletar).

4. Exemplo prático em lista

ListView.builder(
  itemCount: items.length, // quantidade de elementos
  itemBuilder: (context, index) {
    final item = items[index]; // item atual da lista

    return Dismissible(
      key: Key(item), // chave única para o item
      direction: DismissDirection.endToStart, 
      // só permite deslizar da direita para a esquerda

      onDismissed: (direction) {
        items.removeAt(index); // remove da lista
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(content: Text('$item removido')), 
          // mostra aviso na tela
        );
      },

      background: Container(
        color: Colors.red, // cor de fundo
        alignment: Alignment.centerRight, 
        padding: EdgeInsets.symmetric(horizontal: 20),
        child: Icon(Icons.delete, color: Colors.white), 
      ),

      child: ListTile(title: Text(item)), 
    );
  },
);

Comentários do exemplo:

  • ListView.builder: Gera a lista dinamicamente para otimizar a performance.
  • Dismissible: Envolve cada ListTile, tornando-o "deslizável".
  • onDismissed: Remove o item da fonte de dados (a lista `items`) e mostra um SnackBar de confirmação.
  • background: Cria uma área vermelha com um ícone de lixeira que aparece conforme o usuário desliza o item.

5. Vantagens

  • Experiência intuitiva: O usuário entende o gesto sem precisar de instruções.
  • Feedback visual imediato: Cores e ícones ajudam a confirmar a ação.
  • Menos botões na tela: Economiza espaço na interface, resultando em um design mais limpo.
  • Altamente customizável: Pode mudar o comportamento dependendo da direção do deslize.
