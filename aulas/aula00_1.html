Widgets Essenciais do Flutter

Aprenda a utilizar os blocos fundamentais de construção do Flutter: exibição de conteúdo, estrutura de layout e captura de dados com formulários.

Objetivos da Aula

📚 Documentação oficial
  • Dominar a exibição básica de dados com Text, Icon e Image.
  • Organizar elementos em tela utilizando os widgets de layout Column, Row e Center.
  • Capturar e validar entradas do usuário usando TextField, TextFormField e Form.
  • Compreender o papel do GlobalKey<FormState> na validação de campos.
  • Construir um formulário completo e funcional combinando todos esses widgets.

Widgets de Conteúdo

📚 Documentação oficial

1. Text

O widget Text exibe uma cadeia de caracteres na interface com formatação personalizada por meio da propriedade style (`TextStyle`). 

Text(
  'Bem-vindo ao Flutter!',
  style: TextStyle(
    fontSize: 24,
    fontWeight: FontWeight.bold,
    color: Colors.blue,
  ),
)

2. Icon

O widget Icon desenha um ícone vetorial vindo de uma biblioteca de glifos (como `Icons`). É leve e escalável sem perda de qualidade. 

Icon(
  Icons.favorite,
  color: Colors.red,
  size: 36.0,
)

3. Image

O widget Image exibe imagens a partir de diversas fontes. Os construtores nomeados mais comuns são Image.network (para imagens da web) e Image.asset (para arquivos locais definidos no `pubspec.yaml`). 

Image.network(
  'https://flutter.dev/assets/404/dash_nest.png',
  width: 150,
  height: 150,
  fit: BoxFit.cover,
)

Widgets de Layout

📚 Documentação oficial

Column

Dispõe seus widgets filhos em uma linha vertical (um abaixo do outro).

Column(
  mainAxisAlignment: MainAxisAlignment.center,
  children: [
    Text('Item 1'),
    Text('Item 2'),
  ],
)

Row

Dispõe seus widgets filhos em uma linha horizontal (um ao lado do outro).

Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [
    Icon(Icons.star),
    Text('Avaliação'),
  ],
)

Center

Posiciona seu widget filho exatamente no centro do espaço disponível.

Center(
  child: Text(
    'Centralizado'
  ),
)

Widgets de Formulário

📚 Documentação oficial

1. TextField

O TextField é o campo basico para entrada de texto via teclado. Permite capturar eventos como onChanged e controlar o conteúdo com um TextEditingController. 

TextField(
  decoration: InputDecoration(
    labelText: 'Pesquisar',
    prefixIcon: Icon(Icons.search),
    border: OutlineInputBorder(),
  ),
)

2. TextFormField

O TextFormField envolve um `TextField` e adiciona integração nativa ao widget Form. Suporta função de validação (validator) e salvamento (onSaved). 

TextFormField(
  decoration: InputDecoration(labelText: 'E-mail'),
  validator: (value) {
    if (value == null || !value.contains('@')) {
      return 'Informe um e-mail válido';
    }
    return null;
  },
)

3. Form

O widget Form serve como um container para agrupar múltiplos campos de entrada (como `TextFormField`). Ele permite gerenciar, validar e redefinir o estado de todos os seus campos filhos de uma só vez utilizando uma GlobalKey<FormState>. 

Form(
  key: _formKey,
  child: Column(
    children: [
      TextFormField(/* ... */),
      ElevatedButton(
        onPressed: () {
          if (_formKey.currentState!.validate()) {
            ScaffoldMessenger.of(context).showSnackBar(
              SnackBar(content: Text('Formulário válido!')),
            );
          }
        },
        child: Text('Enviar'),
      ),
    ],
  ),
)

Exemplos Práticos Integrados

📚 Documentação oficial

Exemplo 1 — Cartão de Perfil (Center, Column, Row, Image, Icon, Text)

Center(
  child: Column(
    mainAxisAlignment: MainAxisAlignment.center,
    children: [
      Image.network(
        'https://flutter.dev/assets/404/dash_nest.png',
        height: 100,
      ),
      SizedBox(height: 12),
      Text(
        'Dash Flutter',
        style: TextStyle(fontSize: 22, fontWeight: FontWeight.bold),
      ),
      SizedBox(height: 8),
      Row(
        mainAxisAlignment: MainAxisAlignment.center,
        children: [
          Icon(Icons.star, color: Colors.amber),
          SizedBox(width: 4),
          Text('4.9 (Desenvolvedor Mascot)'),
        ],
      ),
    ],
  ),
)

Este código utiliza Center para centralizar a estrutura principal. A Column organiza a imagem (Image.network), o título (Text) e as métricas na vertical. A Row combina o ícone de estrela (Icon) com o texto descritivo lado a lado.

Exemplo 2 — Formulário de Login (Form, TextFormField, Column, Row, Icon, Text)

final _formKey = GlobalKey<FormState>();

Form(
  key: _formKey,
  child: Column(
    crossAxisAlignment: CrossAxisAlignment.stretch,
    children: [
      Row(
        children: [
          Icon(Icons.login, size: 28, color: Colors.blue),
          SizedBox(width: 8),
          Text('Acesse sua conta', style: TextStyle(fontSize: 20)),
        ],
      ),
      SizedBox(height: 16),
      TextFormField(
        decoration: InputDecoration(
          labelText: 'E-mail',
          prefixIcon: Icon(Icons.email),
        ),
        validator: (value) {
          if (value == null || value.isEmpty) {
            return 'Por favor, insira o e-mail';
          }
          return null;
        },
      ),
      SizedBox(height: 12),
      TextFormField(
        obscureText: true,
        decoration: InputDecoration(
          labelText: 'Senha',
          prefixIcon: Icon(Icons.lock),
        ),
        validator: (value) {
          if (value == null || value.length < 6) {
            return 'A senha deve ter pelo menos 6 caracteres';
          }
          return null;
        },
      ),
      SizedBox(height: 20),
      FilledButton(
        onPressed: () {
          if (_formKey.currentState!.validate()) {
            print('Formulário validado com sucesso!');
          }
        },
        child: Text('Entrar'),
      ),
    ],
  ),
)

Neste exemplo, o widget Form gerencia os dois campos de entrada (TextFormField) usando a chave de estado _formKey. Quando o usuário clica no botão, a chamada _formKey.currentState!.validate() aciona as funções de validação de cada campo.
