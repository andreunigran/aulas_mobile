Widgets de Conteúdo

📚 Documentação oficial
  • Text: exibe texto simples na interface. Pode receber estilo, alinhamento, tamanho e outras configurações visuais.
  • RichText / Text.rich: permite combinar trechos com estilos diferentes dentro de um único conteúdo, sendo útil para destacar palavras ou partes específicas.
  • SelectableText: apresenta texto que o usuário pode selecionar e copiar, sendo útil para códigos, identificadores e informações que precisam ser reutilizadas.
  • Icon: apresenta um símbolo gráfico da biblioteca de ícones do Flutter, ajudando a comunicar visualmente uma ação ou informação.
  • Image: apresenta imagens provenientes de diferentes fontes, como arquivos locais, internet, memória ou outros recursos disponíveis para a aplicação.
  • CircleAvatar: apresenta uma imagem, ícone ou inicial dentro de uma área circular, sendo bastante utilizado para representar usuários.
  • FlutterLogo: exibe o logotipo oficial do Flutter e é útil principalmente em exemplos, demonstrações e telas relacionadas ao framework.

Widgets de Layout

📚 Documentação oficial

Organização

  • Row: organiza seus widgets filhos horizontalmente, distribuindo-os ao longo do eixo principal.
  • Column: organiza seus widgets filhos verticalmente, sendo um dos principais componentes para construir formulários e telas em sequência.
  • Stack: coloca widgets uns sobre os outros, permitindo criar sobreposições, como texto sobre imagens ou botões sobre cartões.
  • Positioned: permite definir a posição de um filho dentro de um Stack usando propriedades como top, bottom, left e right.
  • Wrap: distribui os filhos e quebra automaticamente o conteúdo para uma nova linha ou coluna quando o espaço disponível termina.

Tamanho e espaço

  • Container: combina recursos de tamanho, espaçamento, alinhamento e decoração em torno de um único filho, sendo muito utilizado para estruturar e estilizar interfaces.
  • SizedBox: cria um espaço definido ou impõe largura e altura específicas, sendo muito utilizado para controlar espaçamentos entre widgets.
  • Expanded: faz com que um filho de Row, Column ou Flex ocupe o espaço disponível no eixo principal.
  • Flexible: permite que um filho use o espaço disponível de maneira flexível, sem exigir necessariamente que ocupe todo o espaço restante.
  • Padding: adiciona espaço interno ao redor de um widget, ajudando a evitar que os elementos fiquem visualmente encostados.
  • Center / Align: controlam o posicionamento de um filho dentro do espaço disponível, permitindo centralização ou alinhamento em diferentes direções.

Material 3

📚 Documentação oficial

Estrutura, ações e controles

Estrutura: MaterialApp configura a aplicação Material; Scaffold fornece a estrutura básica de uma tela; AppBar cria a barra superior; Card agrupa conteúdo em um cartão; e ListTile organiza informações e ações em uma linha padronizada.

Botões: FilledButton destaca uma ação principal; ElevatedButton representa uma ação importante com destaque visual; OutlinedButton utiliza contorno; TextButton apresenta uma ação mais discreta; IconButton utiliza um ícone como ação; e FloatingActionButton destaca uma ação principal de uma tela.

Seleção: Checkbox permite seleção independente; Radio permite escolher uma opção entre um grupo; Switch representa uma opção liga/desliga; ChoiceChip representa escolhas; FilterChip permite aplicar filtros; e SegmentedButton organiza opções relacionadas em segmentos.

Valores: Slider permite selecionar um valor dentro de um intervalo; RangeSlider permite selecionar simultaneamente um valor mínimo e um máximo.

Entrada: TextField recebe texto; TextFormField adiciona recursos de validação; Form agrupa campos; Autocomplete apresenta sugestões; SearchBar fornece uma interface de pesquisa; e DropdownMenu permite escolher uma opção em um menu.

Feedback: AlertDialog apresenta alertas e decisões; Dialog exibe conteúdo modal; SnackBar mostra mensagens temporárias; Tooltip fornece uma explicação contextual; e Banner apresenta uma mensagem persistente relacionada à interface.

ElevatedButton

📚 Documentação oficial

O que é o ElevatedButton?

ElevatedButton é um botão do Material 3 utilizado para representar uma ação importante na interface. Ele apresenta destaque visual em relação a ações secundárias e executa uma função quando o usuário interage com ele. A ação normalmente é definida pela propriedade onPressed, enquanto o conteúdo visual do botão é definido pelo child.

Principais propriedades

onPressed

Define a função executada quando o usuário pressiona o botão. Quando recebe null, o botão fica desabilitado.

child

Define o conteúdo apresentado dentro do botão. É comum utilizar Text, Icon ou uma combinação desses widgets.

style

Permite personalizar aparência, como cor, tamanho, padding, formato e comportamento visual do botão.

onLongPress

Define uma ação para quando o usuário mantém o botão pressionado por mais tempo.

Exemplo

ElevatedButton(
  onPressed: () {
    print('Botão pressionado');
  },
  child: Text('Salvar'),
)

Neste exemplo, ElevatedButton cria o botão, onPressed define o comportamento executado no clique e Text apresenta o rótulo “Salvar”. A combinação demonstra a estrutura básica de um botão de ação no Flutter.

Navegação

📚 Documentação oficial
  • Navigator: gerencia a pilha de rotas, permitindo abrir novas telas e retornar para telas anteriores.
  • NavigationBar: fornece navegação entre seções principais na parte inferior da tela.
  • NavigationRail: oferece navegação lateral e é especialmente útil em tablets, desktops e telas mais largas.
  • NavigationDrawer: apresenta um menu lateral com opções de navegação ou funcionalidades da aplicação.
  • TabBar + TabBarView: criam uma interface com abas, permitindo alternar entre diferentes conjuntos de conteúdo.
  • MaterialPageRoute: cria uma rota seguindo o comportamento visual e as transições tradicionais do Material.
  • Router / RouterConfig: oferecem uma abordagem declarativa para navegação, adequada a aplicações com fluxos de rotas mais complexos.

Listas, Grades e Scroll

📚 Documentação oficial

ListView: apresenta uma lista linear de widgets que pode ser rolada vertical ou horizontalmente.

ListView.builder: constrói os itens sob demanda, sendo indicado para listas grandes ou cujo conteúdo é gerado dinamicamente.

ListView.separated: cria uma lista com um widget separador entre os itens, facilitando a organização visual.

GridView: organiza widgets em linhas e colunas, formando uma grade rolável.

PageView: permite navegar entre páginas ou painéis, normalmente por deslizamento horizontal.

SingleChildScrollView: permite que um único widget com conteúdo maior que a área disponível seja rolado.

CustomScrollView: permite combinar diferentes Slivers em uma única área de rolagem personalizada.

ReorderableListView: permite ao usuário arrastar itens para alterar a ordem de uma lista.

Slivers

📚 Documentação oficial
  • SliverList: apresenta uma lista eficiente dentro de um CustomScrollView e participa do sistema de rolagem baseado em Slivers.
  • SliverGrid: apresenta uma grade de itens dentro de um CustomScrollView.
  • SliverAppBar: integra a barra superior ao comportamento de rolagem, permitindo efeitos como expansão e recolhimento.
  • SliverToBoxAdapter: permite inserir um widget comum dentro de uma sequência de Slivers.
  • SliverPadding: aplica espaçamento ao redor de outro Sliver.
  • SliverFillRemaining: faz um Sliver ocupar o espaço restante disponível na área de rolagem.
  • SliverPersistentHeader: cria um cabeçalho que pode permanecer visível ou reagir à rolagem conforme a configuração.

Formulários e Entrada de Dados

📚 Documentação oficial
  • Form: agrupa campos de entrada relacionados e permite executar operações de validação e salvamento de forma organizada.
  • TextFormField: campo de texto integrado a Form, permitindo definir regras de validação e mensagens de erro.
  • InputDecoration: configura a apresentação de campos de entrada, incluindo rótulo, dica, ícone, borda e mensagens de validação.
  • DropdownMenu: apresenta opções em um menu para que o usuário selecione um valor.
  • Autocomplete: apresenta sugestões enquanto o usuário digita, facilitando a escolha de valores existentes.
  • SearchBar / SearchAnchor: fornecem componentes para construir experiências de pesquisa e seleção de resultados.

Gestos e Interação

📚 Documentação oficial

GestureDetector: detecta diferentes gestos do usuário, como toque, arraste, toque duplo, toque prolongado e outros eventos de interação.

InkWell: adiciona interação por toque com efeitos visuais característicos do Material, como o efeito de ondulação.

Dismissible: permite que um item seja dispensado, normalmente por meio de um gesto de arrastar.

Draggable: transforma um widget em um elemento que pode ser arrastado pela interface.

DragTarget: define uma área capaz de receber um elemento que está sendo arrastado.

AbsorbPointer / IgnorePointer: controlam a passagem de eventos de ponteiro para os widgets, permitindo bloquear ou ignorar interações.

Exemplos de Código

📚 Documentação oficial

Exemplo 1 — Layout básico

Scaffold(
  appBar: AppBar(title: Text('Cadastro')),
  body: SafeArea(
    child: Padding(
      padding: EdgeInsets.all(16),
      child: Column(
        children: [
          Text('Nome'),
          TextField(),
          SizedBox(height: 16),
          FilledButton(
            onPressed: () {},
            child: Text('Salvar'),
          ),
        ],
      ),
    ),
  ),
)

Scaffold estrutura a tela; AppBar cria o cabeçalho; SafeArea evita áreas inseguras; Padding cria espaçamento; Column organiza os elementos verticalmente; TextField recebe o nome; SizedBox cria espaço; e FilledButton executa a ação de salvar. Esses componentes trabalham juntos para formar uma tela simples de cadastro.

Exemplo 2 — Lista dinâmica

ListView.builder(
  itemCount: itens.length,
  itemBuilder: (context, index) {
    return ListTile(
      leading: Icon(Icons.person),
      title: Text(itens[index]),
      onTap: () {},
    );
  },
)

ListView.builder cria uma lista dinâmica; itemCount informa quantos elementos serão apresentados; itemBuilder constrói cada item; ListTile organiza o conteúdo de uma linha; Icon apresenta o ícone; Text mostra o valor do item; e onTap define a ação executada quando o usuário toca na linha.

Exemplo 3 — Estado

int contador = 0;

FilledButton(
  onPressed: () {
    setState(() {
      contador++;
    });
  },
  child: Text('Adicionar'),
)

A variável contador armazena o estado atual. O FilledButton executa uma ação ao ser pressionado. Dentro de setState, o valor é incrementado e o Flutter reconstrói a interface para apresentar o novo estado.
