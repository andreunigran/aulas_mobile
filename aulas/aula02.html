Introdução ao Flutter e Setup do Ambiente

Nesta primeira aula, vamos conhecer o Flutter, por que ele é uma escolha moderna para o desenvolvimento e como configurar seu ambiente.

O que é Flutter e suas Vantagens?

Flutter é um framework de código aberto criado pela Google para desenvolver aplicativos com uma única base de código que roda em Android, iOS, Web e Desktop. Aplicativos famosos como o Google Ads, Nubank e iFood usam Flutter em produção.

Hot Reload

Permite ver alterações no código em tempo real sem reiniciar o app, acelerando o desenvolvimento.

Alto Desempenho

O código é compilado diretamente para nativo, garantindo performance excelente.

UI Moderna

Componentes visuais (widgets) ricos e personalizáveis para criar interfaces incríveis.

Produtividade

Menos tempo para desenvolver, testar e publicar em múltiplas plataformas.

Comunidade Ativa

Grande quantidade de pacotes prontos (em pub.dev) e documentação extensa.

Arquitetura do Flutter

Flutter é composto por três camadas principais. Esse modelo permite que ele não dependa de componentes nativos da plataforma, o que resulta em maior controle e personalização visual.

1. Framework (Dart)

A camada superior, onde você escreve todo o seu código usando a linguagem Dart e a vasta biblioteca de widgets do Flutter.

2. Engine (C/C++)

O coração do Flutter. É responsável por renderizar a interface na tela usando o motor gráfico Skia, além de gerenciar a entrada, saída e a execução do código Dart.

3. Embedder

A camada de integração específica da plataforma. Ela conecta o app ao sistema operacional (Android/iOS/Web/Desktop), gerenciando a janela, os eventos e a comunicação com serviços nativos.

O que é Dart?

Dart é uma linguagem moderna e fácil de aprender, criada pela Google. Ela é orientada a objetos, com sintaxe semelhante a JavaScript, Java e C#. Com Dart, você escreve a lógica de negócios e a interface do seu app Flutter.

  • Tipagem forte e segura (sound null safety).
  • Suporte a programação assíncrona com `async/await`.
  • Excelente performance com compilação JIT (para desenvolvimento) e AOT (para produção).

Setup do Ambiente de Desenvolvimento

Requisitos Mínimos

  • Sistema Operacional: Windows 10+, macOS ou Linux.
  • Espaço em disco: No mínimo 2.8 GB (sem contar o Android Studio).
  • Git: Necessário para o Flutter funcionar corretamente.

Passo 1: Instalar o Flutter SDK

  1. Baixar o Flutter SDK no site oficial: flutter.dev.
  2. Descompactar em uma pasta como `C:\src\flutter` ou `~/development/flutter`.
  3. Adicionar o caminho completo da pasta `flutter\bin` à sua variável de ambiente `PATH`.

Passo 2: Instalar a IDE e Plugins

VS Code

Instale as extensões "Flutter" e "Dart" diretamente da marketplace do editor.

Android Studio

Vá em `Plugins > Marketplace` e instale os plugins "Flutter" e "Dart".

Passo 3: Instalar o Android SDK e Emulador

A forma mais fácil de fazer isso é através do Android Studio. Após instalá-lo, use o `AVD Manager` para criar e configurar um emulador Android.

Passo 4: Verificar o Ambiente

Abra um novo terminal e rode `flutter doctor`. Ele analisará sua instalação e indicará se algo precisa ser corrigido.

flutter doctor

Criando e Rodando seu Primeiro App

Após a instalação, teste se tudo está funcionando criando e rodando um app de exemplo. Abra seu terminal e execute os seguintes comandos:

# Cria um novo projeto chamado hello_flutter
flutter create hello_flutter

# Entra na pasta do projeto
cd hello_flutter

# Roda o aplicativo (com um emulador aberto ou celular conectado)
flutter run

Se tudo estiver correto, o aplicativo de demonstração do Flutter será iniciado no seu dispositivo ou emulador.

Problemas Comuns no Setup

  • Comando `flutter` não reconhecido: Verifique se o caminho para a pasta `bin` do Flutter foi adicionado corretamente à variável `PATH` do seu sistema.
  • `flutter doctor` mostra pendências: Leia a saída com atenção. Geralmente, ele informa exatamente o que falta, como aceitar as licenças do Android (`flutter doctor --android-licenses`).
  • Emulador Android não inicia: Confira se a virtualização de hardware (VT-x) está ativada na BIOS do seu computador.
  • Celular não aparece: Certifique-se de que a "Depuração USB" está ativada nas Opções do Desenvolvedor do seu Android e que você autorizou a conexão no popup que aparece no celular.

Exercício Prático

Objetivo

Configurar seu ambiente Flutter completamente e rodar o aplicativo de exemplo.

Passos

  1. Baixe e configure o Flutter SDK no seu sistema.
  2. Instale a IDE de sua escolha (VS Code ou Android Studio) com os plugins do Flutter e Dart.
  3. Execute `flutter doctor` e corrija todos os possíveis erros ou pendências.
  4. Crie um novo projeto com o comando `flutter create hello_flutter`.
  5. Rode o aplicativo com `flutter run` em um emulador ou celular físico.
  6. Envie uma captura de tela do app rodando como evidência.

Referências e Dúvidas Frequentes

Dúvidas Frequentes

  • Preciso de um Mac para iOS? Sim, para compilar para iOS é necessário um macOS com Xcode.
  • O VS Code é suficiente? Sim, desde que o Android SDK esteja corretamente instalado.
  • O Flutter é só para mobile? Não. Ele também permite criar apps para Web, Windows, macOS e Linux.
