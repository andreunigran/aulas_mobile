Guia Completo do ListView no Flutter

Dominando listas, performance e boas práticas.

O que é o ListView e por que é crucial?

ListView é um widget de rolagem que renderiza uma sequência de itens em uma única dimensão (vertical por padrão). Ele é otimizado para performance, pois virtualiza os itens: só constrói e renderiza o que está visível na tela, economizando memória e poder de processamento.

Quando Usar?

Sempre que precisar mostrar coleções de tamanho variável, como dados de uma API, catálogos de produtos, listas de mensagens ou menus.

Construtores Principais

  • ListView(): Para listas pequenas e estáticas.
  • ListView.builder(): Para listas longas ou dinâmicas (a melhor escolha para performance).
  • ListView.separated(): Igual ao `builder`, mas com um construtor para separadores entre os itens.
  • ListView.custom(): Para controle total sobre a construção dos itens.

Estrutura Básica (ListView com `children`)

Quando você já tem uma lista pequena e estática de widgets, a forma mais direta é usar o construtor padrão.

Performance: Todos os itens na lista `children` são construídos de uma só vez. Evite essa abordagem para listas longas para não impactar a memória e o tempo de build.

ListView(
  padding: EdgeInsets.all(8),
  children: <Widget>[
    ListTile(title: Text("Item 1")),
    ListTile(title: Text("Item 2")),
    ListTile(title: Text("Item 3")),
  ],
);

Armadilha Comum

Colocar um `ListView` dentro de uma `Column` sem uma altura definida causará um erro de "unbounded height". Para resolver, envolva o `ListView` em um widget `Expanded` ou `SizedBox` com altura fixa.

ListView.builder (Listas Grandes/Dinâmicas)

Para listas extensas, este construtor constrói itens sob demanda (lazy building), o que é fundamental para a performance.

O `itemBuilder` só é chamado para os índices que estão visíveis na tela, reduzindo drasticamente o custo de construção e o consumo de memória.

ListView.builder(
  itemCount: items.length,
  itemBuilder: (context, index) {
    final item = items[index];
    return ListTile(
      leading: Icon(Icons.star),
      title: Text("Item $index"),
      subtitle: Text("Subtítulo do item $index"),
      onTap: () {}, // ação
    );
  },
);

ListView.separated (Itens + Separadores)

Ideal para quando você precisa intercalar divisores ou espaçadores entre os itens de forma eficiente.

A grande vantagem é a clareza do código, separando a lógica de construção do item da lógica de construção do separador. A performance continua sendo otimizada (lazy building).

ListView.separated(
  itemCount: 20,
  itemBuilder: (context, index) {
    return ListTile(title: Text("Elemento $index"));
  },
  separatorBuilder: (context, index) {
    return Divider(height: 0); // Ou um SizedBox para espaçamento
  },
);

Scroll Horizontal

Para criar carrosséis ou listas laterais, basta mudar a direção da rolagem e garantir que o `ListView` tenha uma altura fixa. 

SizedBox(
  height: 140, // Altura fixa é crucial para listas horizontais
  child: ListView(
    scrollDirection: Axis.horizontal,
    children: <Widget>[
      Container(width: 120, margin: EdgeInsets.all(8), color: Colors.red),
      Container(width: 120, margin: EdgeInsets.all(8), color: Colors.green),
      Container(width: 120, margin: EdgeInsets.all(8), color: Colors.blue),
    ],
  ),
);

Variações Úteis (Combinando Widgets)

Combine o `ListView` com outros widgets para criar experiências ricas e interativas.

  • `ListTile`: Widget padrão para itens de lista com ícone, título, subtítulo e ação.
  • `Card`: Adiciona uma elevação e bordas arredondadas, criando uma aparência moderna.
  • `Dismissible`: Permite que o usuário arraste um item para removê-lo.
  • `RefreshIndicator`: Adiciona a funcionalidade "puxar para atualizar".
RefreshIndicator(
  onRefresh: () async => controller.reload(),
  child: ListView.builder(
    itemCount: products.length,
    itemBuilder: (context, i) {
      final p = products[i];
      return Dismissible(
        key: ValueKey(p.id),
        background: Container(color: Colors.red),
        onDismissed: (_) => controller.remove(p.id),
        child: Card(
          margin: EdgeInsets.symmetric(horizontal: 12, vertical: 6),
          child: ListTile(
            title: Text(p.name),
            onTap: () {},
          ),
        ),
      );
    },
  ),
);

Desafios e Boas Práticas

Checklist Rápido de Decisão

  • Tamanho da lista: Pequena e estática? Use `ListView()`. Grande ou dinâmica? Use `ListView.builder`.
  • Separadores: Precisa de divisores entre os itens? Use `ListView.separated`.
  • Constraints: Dentro de uma `Column`? Envolva o `ListView` em `Expanded` ou `SizedBox`.
  • Performance: Se os itens tiverem altura fixa, use a propriedade `itemExtent`. Para itens com estado, use uma `Key` estável (ex: `ValueKey(item.id)`).

Exemplo Completo com Boas Práticas

Este exemplo demonstra o uso de `ListView.builder` com `Card` e `ListTile` para criar uma lista performática e visualmente agradável.

class MyListView extends StatelessWidget {
  final List<String> items = List.generate(50, (i) => "Item $i");

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text("Exemplo ListView")),
      body: ListView.builder(
        itemCount: items.length,
        itemBuilder: (context, index) {
          return Card(
            margin: EdgeInsets.symmetric(horizontal: 12, vertical: 6),
            child: ListTile(
              leading: CircleAvatar(child: Text("${index + 1}")),
              title: Text(items[index]),
              subtitle: Text("Detalhes do ${items[index]}"),
              trailing: Icon(Icons.chevron_right),
              onTap: () {
                ScaffoldMessenger.of(context).showSnackBar(
                  SnackBar(content: Text('Clicou no ${items[index]}')),
                );
              },
            ),
          );
        },
      ),
    );
  }
}
