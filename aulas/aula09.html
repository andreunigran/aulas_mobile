Guia de Armazenamento Seguro e Biometria no Flutter

Protegendo dados sensíveis com `flutter_secure_storage` e `local_authentication`.

O que é `flutter_secure_storage`?

É uma biblioteca para armazenar dados de forma segura e criptografada no dispositivo. Diferente do `shared_preferences` (que armazena dados em texto simples), o `flutter_secure_storage` oferece um nível extra de segurança ao usar os mecanismos nativos de cada plataforma.

É ideal para guardar informações sensíveis, como tokens de autenticação, senhas, chaves de API e outros dados que exigem proteção.

Como Funciona?

  • Android: Utiliza o **Keystore** para criptografar os dados.
  • iOS: Usa o **Keychain** para o armazenamento seguro.

Instalação

Para adicionar o pacote ao seu projeto, execute o seguinte comando no terminal:

flutter pub add flutter_secure_storage

Isso adicionará a dependência ao seu arquivo `pubspec.yaml`:

dependencies:
  flutter_secure_storage: ^9.0.0

Uso Básico

A utilização do pacote é simples e baseada em operações de chave-valor. O exemplo abaixo mostra as operações essenciais para gerenciar um token de autenticação.

import 'package:flutter_secure_storage/flutter_secure_storage.dart';

// 1. Crie uma instância do storage
final storage = FlutterSecureStorage();

// 2. Função para salvar um dado
Future<void> salvarToken(String token) async {
  await storage.write(key: 'auth_token', value: token);
}

// 3. Função para carregar um dado
Future<String?> carregarToken() async {
  return await storage.read(key: 'auth_token');
}

// 4. Função para remover um dado (ex: logout)
Future<void> removerToken() async {
  await storage.delete(key: 'auth_token');
}

// 5. Função para verificar se o usuário está logado
Future<bool> isUserLoggedIn() async {
  final token = await carregarToken();
  return token != null;
}

Autenticação Biométrica

Para adicionar uma camada extra de segurança, você pode usar a autenticação biométrica (impressão digital ou reconhecimento facial) para permitir o acesso aos dados seguros. Para isso, usamos o pacote `local_authentication`.

Instalação

Adicione o pacote ao seu projeto:

flutter pub add local_authentication

Exemplo de Biometria

O código abaixo mostra como verificar se a biometria está disponível e como solicitar a autenticação do usuário.

import 'package:local_authentication/local_authentication.dart';
import 'package:flutter/material.dart';

class BiometricAuthScreen extends StatefulWidget {
  @override
  _BiometricAuthScreenState createState() => _BiometricAuthScreenState();
}

class _BiometricAuthScreenState extends State<BiometricAuthScreen> {
  final LocalAuthentication auth = LocalAuthentication();
  bool _canCheckBiometrics = false;
  bool _isAuthenticated = false;

  @override
  void initState() {
    super.initState();
    _checkBiometrics();
  }

  Future<void> _checkBiometrics() async {
    final canCheck = await auth.canCheckBiometrics;
    setState(() {
      _canCheckBiometrics = canCheck;
    });
  }

  Future<void> _authenticate() async {
    bool authenticated = false;
    try {
      authenticated = await auth.authenticate(
        localizedReason: 'Por favor, autentique-se para continuar',
        options: const AuthenticationOptions(stickyAuth: true),
      );
    } catch (e) {
      // Tratar erro
    }
    setState(() {
      _isAuthenticated = authenticated;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Autenticação')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text(_canCheckBiometrics ? 'Biometria disponível' : 'Biometria não disponível'),
            SizedBox(height: 20),
            ElevatedButton(
              onPressed: _authenticate,
              child: Text(_isAuthenticated ? 'Autenticado!' : 'Autenticar'),
            ),
          ],
        ),
      ),
    );
  }
}

Conclusão e Boas Práticas

  • Sempre use `flutter_secure_storage` para dados sensíveis. Para configurações simples e não secretas, `shared_preferences` pode ser suficiente.
  • Combine o armazenamento seguro com a autenticação biométrica para criar uma camada adicional de proteção em fluxos críticos, como acesso a áreas restritas do app ou confirmação de transações.
  • Sempre trate os possíveis erros ao tentar autenticar o usuário.
