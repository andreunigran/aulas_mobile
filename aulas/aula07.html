Guia de SharedPreferences no Flutter

Armazenando dados simples de forma persistente.

O que é SharedPreferences?

`SharedPreferences` é uma API usada para armazenar pequenas quantidades de dados simples em formato chave-valor. Esses dados são persistidos no armazenamento interno do dispositivo e podem ser acessados mesmo após o aplicativo ser fechado e reaberto, sendo ideal para salvar configurações do usuário ou o estado do aplicativo.

Características Principais

  • Dados Simples: Permite salvar tipos de dados primitivos como `int`, `double`, `bool`, `String` e listas de `String`.
  • Leve e Simples: Ideal para armazenar preferências, como tema escuro, status de login, ou a última tela visitada.
  • Chave-Valor: Os dados são armazenados como pares, onde cada valor é associado a uma chave única.
  • Persistente: Os dados salvos permanecem até que sejam explicitamente removidos ou o aplicativo seja desinstalado.

Instalação

Para adicionar o pacote `shared_preferences` ao seu projeto Flutter, execute o seguinte comando no terminal:

flutter pub add shared_preferences

Isso adicionará a dependência ao seu arquivo `pubspec.yaml`:

dependencies:
  shared_preferences: ^2.2.2

Como Funciona em Cada Plataforma

O pacote `shared_preferences` abstrai a implementação nativa de cada sistema operacional, fornecendo uma API única em Dart.

  • Android: Utiliza a API nativa `SharedPreferences` do Android para salvar os dados localmente.
  • iOS: Utiliza o `NSUserDefaults`, que é o equivalente ao `SharedPreferences` no ecossistema da Apple, para persistir os dados.

Uso Básico

A utilização do pacote envolve obter uma instância do `SharedPreferences` e, a partir dela, chamar os métodos para salvar, ler ou remover dados de forma assíncrona.

import 'package:shared_preferences/shared_preferences.dart';

// Função para salvar um dado (ex: nome do usuário)
Future<void> salvarNome(String nome) async {
  final prefs = await SharedPreferences.getInstance();
  await prefs.setString('username', nome);
}

// Função para carregar um dado
Future<String?> carregarNome() async {
  final prefs = await SharedPreferences.getInstance();
  // Retorna o nome salvo, ou null se a chave não existir
  return prefs.getString('username');
}

// Função para remover um dado
Future<void> removerNome() async {
  final prefs = await SharedPreferences.getInstance();
  await prefs.remove('username');
}

Operações Suportadas

O `SharedPreferences` suporta os tipos de dados primitivos mais comuns, além de listas de strings.

Operação Descrição
setString(key, value)Armazena uma `String`.
setInt(key, value)Armazena um `int`.
setBool(key, value)Armazena um `bool`.
setDouble(key, value)Armazena um `double`.
setStringList(key, value)Armazena uma `List`.
getString(key)Recupera uma `String`.
getInt(key)Recupera um `int`.
getBool(key)Recupera um `bool`.
getDouble(key)Recupera um `double`.
getStringList(key)Recupera uma `List`.
remove(key)Remove o dado armazenado na chave especificada.
clear()Remove todos os dados armazenados.

Conclusão e Boas Práticas

`SharedPreferences` é uma ferramenta excelente para persistência de dados simples e não sensíveis. Para informações críticas como tokens de autenticação ou senhas, prefira sempre o `flutter_secure_storage`.

  • Use para dados não sensíveis: Configurações de UI (tema, idioma), flags de controle (ex: "já viu o tutorial?"), etc.
  • Seja consistente com as chaves: Crie constantes para as chaves para evitar erros de digitação.
  • Cuidado com dados grandes: Evite armazenar grandes volumes de dados, pois isso pode impactar a performance.
