Firebase no Flutter

Integrando Backend e Funcionalidades Avançadas em Aplicações Mobile

Introdução

Documentação oficial

O Firebase é uma plataforma de desenvolvimento de aplicativos móveis e web do Google, que funciona como um Backend as a Service (BaaS). Ele fornece ferramentas prontas para autenticação, base de dados, notificações push, armazenamento de ficheiros, analytics e muito mais.

Integrar o Firebase ao Flutter permite adicionar funcionalidades complexas rapidamente, sem a necessidade de gerir uma infraestrutura de backend própria.

Principais Pacotes Flutter + Firebase:

  • firebase_core: Essencial para inicialização.
  • firebase_auth: Autenticação de utilizadores.
  • cloud_firestore: Base de dados NoSQL escalável.
  • firebase_storage: Armazenamento de ficheiros (imagens, vídeos).
  • firebase_messaging: Notificações push.
  • firebase_database: Base de dados Realtime NoSQL (alternativa ao Firestore).

Configuração do Projeto

Documentação oficial

Para utilizar os serviços do Firebase no seu projeto Flutter, primeiro precisa de adicionar as dependências necessárias ao seu ficheiro pubspec.yaml.

dependencies:
  flutter:
    sdk: flutter
  
  # Dependência principal - OBRIGATÓRIA
  firebase_core: ^2.30.0 # Use a versão mais recente
  
  # Adicione os pacotes dos serviços que vai usar:
  firebase_auth: ^4.17.0
  cloud_firestore: ^4.15.0
  google_sign_in: ^6.2.1 # Necessário para Login com Google
  flutter_facebook_auth: ^6.1.1 # Necessário para Login com Facebook
  firebase_storage: ^11.6.0
  firebase_messaging: ^14.7.10
  firebase_database: ^10.4.0
  
  # Outras dependências do seu projeto...

Após adicionar as dependências, execute o comando no terminal, na pasta raiz do seu projeto, para descarregar e instalar os pacotes:

flutter pub get

Este comando lê o ficheiro pubspec.yaml e baixa as versões especificadas das bibliotecas (e as suas dependências) para a pasta .dart_tool/package_config.json e .pub-cache do seu ambiente.

Pré-requisitos para Usar o FlutterFire CLI

Documentação oficial

O FlutterFire CLI é a ferramenta recomendada para configurar o Firebase no seu projeto Flutter de forma automatizada. Antes de usá-la, certifique-se de ter:

  • Node.js e npm instalados: O Firebase CLI (uma dependência) requer Node.js. Verifique com node -v e npm -v.
  • Firebase CLI instalado: Instale globalmente via npm: 
    npm install -g firebase-tools
  • Login no Firebase CLI: Autentique-se com sua conta Google no terminal: 
    firebase login
  • FlutterFire CLI instalado: Instale globalmente via Dart pub: 
    dart pub global activate flutterfire_cli

Com estes pré-requisitos cumpridos, pode navegar até à pasta raiz do seu projeto Flutter no terminal e executar flutterfire configure para iniciar a configuração guiada.

firebase_core

Documentação oficial

O pacote firebase_core é o ponto de partida obrigatório. Ele permite que a aplicação Flutter se conecte à plataforma Firebase e inicialize os seus serviços.

A sua inicialização deve ocorrer antes de usar qualquer outro pacote do Firebase, geralmente no método main().

import 'package:flutter/material.dart';
import 'package:firebase_core/firebase_core.dart';
// Importe as opções geradas pelo FlutterFire CLI
import 'firebase_options.dart'; 

void main() async {
  // Garante que os bindings do Flutter foram inicializados
  WidgetsFlutterBinding.ensureInitialized();
  
  // Inicializa o Firebase usando as opções da plataforma atual
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );
  
  runApp(MyApp());
}

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: Text('Firebase App')),
        body: Center(child: Text('Firebase inicializado!')),
      ),
    );
  }
}

firebase_auth

Documentação oficial

O firebase_auth fornece funcionalidades completas de autenticação, permitindo que os utilizadores façam login, se registem e gerem as suas contas usando diversos provedores.

Login e Registo com Email/Senha

import 'package:firebase_auth/firebase_auth.dart';

FirebaseAuth auth = FirebaseAuth.instance;

// Login
Future signInWithEmailPassword(String email, String password) async {
  try {
    UserCredential userCredential = await auth.signInWithEmailAndPassword(email: email, password: password);
    print('Utilizador logado: ${userCredential.user?.uid}');
  } on FirebaseAuthException catch (e) { print('Erro de login: ${e.message}'); }
}

// Criar conta
Future createUserWithEmailPassword(String email, String password) async {
  try {
    UserCredential userCredential = await auth.createUserWithEmailAndPassword(email: email, password: password);
    print('Utilizador criado: ${userCredential.user?.uid}');
  } on FirebaseAuthException catch (e) { print('Erro ao criar: ${e.message}'); }
}

// Logout
Future signOut() async {
  await auth.signOut();
  print('Utilizador deslogado.');
}

Login com Google

Requer o pacote google_sign_in e configuração específica na consola Firebase e nas plataformas Android/iOS.

import 'package:firebase_auth/firebase_auth.dart';
import 'package:google_sign_in/google_sign_in.dart';

Future signInWithGoogle() async {
  try {
    // Inicia o fluxo de login do Google
    final GoogleSignInAccount? googleUser = await GoogleSignIn().signIn();
    if (googleUser == null) return null; // Utilizador cancelou

    // Obtém os detalhes de autenticação do pedido
    final GoogleSignInAuthentication googleAuth = await googleUser.authentication;

    // Cria uma credencial Firebase
    final OAuthCredential credential = GoogleAuthProvider.credential(
      accessToken: googleAuth.accessToken,
      idToken: googleAuth.idToken,
    );

    // Faz login no Firebase com a credencial do Google
    print('Login com Google bem-sucedido!');
    return await FirebaseAuth.instance.signInWithCredential(credential);
  } catch (e) {
    print("Erro no login com Google: $e");
    return null;
  }
}

Login com Facebook

Requer o pacote flutter_facebook_auth e configuração detalhada na consola Firebase, no portal de desenvolvedores do Facebook e nas plataformas Android/iOS.

import 'package:firebase_auth/firebase_auth.dart';
import 'package:flutter_facebook_auth/flutter_facebook_auth.dart';

Future signInWithFacebook() async {
  try {
    // Inicia o fluxo de login do Facebook
    final LoginResult result = await FacebookAuth.instance.login(); 

    if (result.status == LoginStatus.success) {
      // Obtém o token de acesso
      final AccessToken accessToken = result.accessToken!;
      
      // Cria uma credencial Firebase
      final OAuthCredential credential = FacebookAuthProvider.credential(accessToken.tokenString);
      
      // Faz login no Firebase com a credencial do Facebook
      print('Login com Facebook bem-sucedido!');
      return await FirebaseAuth.instance.signInWithCredential(credential);
    } else {
      print('Login com Facebook cancelado ou falhou: ${result.message}');
      return null;
    }
  } catch (e) {
    print("Erro no login com Facebook: $e");
    return null;
  }
}

cloud_firestore

Documentação oficial

O Cloud Firestore é uma base de dados NoSQL flexível e escalável. Ele armazena dados em documentos, organizados em coleções, e oferece sincronização em tempo real.

import 'package:cloud_firestore/cloud_firestore.dart';

FirebaseFirestore firestore = FirebaseFirestore.instance;

// Adicionar um documento
Future addUser(String userId, String nome, String email) {
  return firestore.collection('utilizadores').doc(userId).set({
        'nomeCompleto': nome, 'email': email, 'dataRegisto': Timestamp.now(),
      })
      .then((_) => print("Utilizador Adicionado"))
      .catchError((e) => print("Falha ao adicionar: $e"));
}

// Ler um documento
Future getUserData(String userId) async {
  DocumentSnapshot snapshot = await firestore.collection('utilizadores').doc(userId).get();
  if (snapshot.exists) print('Dados: ${snapshot.data()}');
  else print('Não encontrado!');
}

// Ler todos os documentos
Future getAllUsers() async {
   QuerySnapshot query = await firestore.collection('utilizadores').get();
   query.docs.forEach((doc) => print('ID: ${doc.id} => Dados: ${doc.data()}'));
}

firebase_storage

Documentação oficial

O Firebase Storage é ideal para armazenar e servir conteúdo gerado pelo utilizador, como fotos e vídeos. É robusto, seguro e escalável.

Combine com image_picker para selecionar ficheiros e fazer o upload.

import 'dart:io';
import 'package:firebase_storage/firebase_storage.dart';
import 'package:image_picker/image_picker.dart';

FirebaseStorage storage = FirebaseStorage.instance;

Future uploadFile() async {
  final XFile? image = await ImagePicker().pickImage(source: ImageSource.gallery);
  if (image == null) return;

  File file = File(image.path);
  String fileName = 'uploads/${DateTime.now().millisecondsSinceEpoch}.jpg';
  
  try {
    Reference ref = storage.ref().child(fileName);
    UploadTask uploadTask = ref.putFile(file);
    await uploadTask;
    String downloadURL = await ref.getDownloadURL();
    print('Upload concluído! URL: $downloadURL');
  } on FirebaseException catch (e) { print('Erro no upload: ${e.message}'); }
}

firebase_messaging

Documentação oficial

O Firebase Cloud Messaging (FCM) permite enviar notificações push e mensagens de dados para engajar utilizadores.

import 'package:firebase_messaging/firebase_messaging.dart';

FirebaseMessaging messaging = FirebaseMessaging.instance;

Future setupMessaging() async {
  // Solicita permissão
  NotificationSettings settings = await messaging.requestPermission();
  print('Permissão: ${settings.authorizationStatus}');

  // Obtém o token do dispositivo
  String? token = await messaging.getToken();
  print("Token FCM: $token");

  // Escuta mensagens em primeiro plano
  FirebaseMessaging.onMessage.listen((RemoteMessage message) {
    print('Mensagem recebida: ${message.notification?.title}');
    // Exibir notificação local ou atualizar UI
  });

  // Configurar handler para background (requer função top-level)
  // FirebaseMessaging.onBackgroundMessage(_backgroundHandler);
}

Realtime Database

Documentação oficial

O Firebase Realtime Database armazena dados como um grande JSON e sincroniza em tempo real. Ideal para apps com baixa latência e atualizações constantes.

import 'package:firebase_database/firebase_database.dart';

FirebaseDatabase database = FirebaseDatabase.instance;

// Escrever dados
void writeData() {
  DatabaseReference ref = database.ref('users/user1');
  ref.set({'name': 'John Doe', 'email': 'john@example.com'});
  print("Dados escritos.");
}
// Escrever dados
void writeDataIDGereado() {
  DatabaseReference ref = database.ref('users').push();

// Ler dados uma vez
Future readData() async {
