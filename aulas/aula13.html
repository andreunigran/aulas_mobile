Guia do Hive para Flutter

Dominando a persistência de dados local de forma rápida e eficiente.

O que é Hive?

Documentação oficial

Hive é um banco de dados NoSQL inovador, rápido e leve, escrito inteiramente em Dart e otimizado para o ecossistema Flutter. Sua arquitetura "offline-first" garante que o aplicativo funcione perfeitamente sem conexão com a internet. Diferente de soluções tradicionais como o SQLite, Hive opera com um sistema de chave/valor, eliminando a necessidade de queries SQL complexas e simplificando a manipulação de dados.

Por que usar Hive?

Documentação oficial

Desempenho

Oferece operações de leitura e escrita extremamente rápidas, superando muitas outras soluções de armazenamento local.

Facilidade

Possui uma API simples e intuitiva, com configuração mínima, permitindo que você comece a usá-lo em minutos.

Flexibilidade

Armazena desde tipos de dados primitivos (int, String) até objetos Dart complexos, através de TypeAdapters.

Compatibilidade

Funciona perfeitamente em todas as plataformas suportadas pelo Flutter: Android, iOS, Web, Windows, macOS e Linux.

Instalação no Flutter

Documentação oficial

1. Adicionar dependências

Adicione as seguintes linhas ao seu arquivo `pubspec.yaml`:

dependencies:
  hive: ^2.2.3 # Use a versão mais recente
  hive_flutter: ^1.1.0 # Use a versão mais recente

dev_dependencies:
  hive_generator: ^1.1.3 # Use a versão mais recente
  build_runner: ^2.1.11 # Use a versão mais recente

2. Inicializar no main()

Antes de rodar o seu app, inicialize o Hive. O `hive_flutter` simplifica isso.

import 'package:hive_flutter/hive_flutter.dart';

void main() async {
  await Hive.initFlutter();
  runApp(MyApp());
}

Hive no Android e iOS

Documentação oficial

A grande vantagem do Hive é que o mesmo código Dart funciona nativamente em ambas as plataformas sem a necessidade de configurações adicionais ou escrita de código nativo.

  • ✓Android: O Hive salva os dados em arquivos dentro do diretório interno do aplicativo, que é seguro e não requer permissões extras.
  • ✓iOS: De forma similar, os dados são armazenados no diretório de documentos da aplicação, seguindo as diretrizes da Apple.

Conceito de Box

Documentação oficial

Um Box é a unidade fundamental de armazenamento no Hive. Pense nele como uma "tabela" em um banco de dados tradicional ou, mais precisamente, como um `Map` persistente que armazena pares de chave/valor. Você pode criar quantos boxes precisar para organizar os dados da sua aplicação.

// 1. Abrir um box (será criado se não existir)
var box = await Hive.openBox('configuracoes');

// 2. Escrever dados
box.put('theme', 'dark');
box.put('notificationsEnabled', true);

// 3. Ler dados
var theme = box.get('theme'); // Retorna 'dark'
print(theme);

CRUD com Hive

Documentação oficial

As operações básicas de banco de dados (Criar, Ler, Atualizar, Deletar) são extremamente simples com a API do Hive.

Create (Inserir) / Update (Atualizar)

O método `put()` insere um novo valor se a chave não existir, ou atualiza o valor existente se a chave já estiver no box.

var box = Hive.box('users');
// Inserindo
await box.put('user1', {'name': 'Ana', 'age': 25});
// Atualizando
await box.put('user1', {'name': 'Ana Clara', 'age': 26});

Read (Ler)

var user = box.get('user1');
print(user['name']); // Saída: Ana Clara

Delete (Remover)

await box.delete('user1');

Armazenando Objetos

Documentação oficial

Para armazenar objetos de classes personalizadas, você precisa criar um `TypeAdapter`, que ensina o Hive a converter seu objeto de/para um formato binário. A forma mais fácil é usando anotações e o `hive_generator`.

// 1. Anote sua classe
part 'user.g.dart'; // O build_runner irá gerar este arquivo

@HiveType(typeId: 1) // typeId deve ser único por classe
class User {
  @HiveField(0) // Índices devem ser únicos dentro da classe
  String name;

  @HiveField(1)
  int age;

  User({required this.name, required this.age});
}

// 2. Registre o adapter antes de usar o box
Hive.registerAdapter(UserAdapter());

// 3. Use normalmente
var userBox = await Hive.openBox('userBox');
await userBox.put('currentUser', User(name: 'Bia', age: 30));

Integração com Flutter

Documentação oficial

O pacote `hive_flutter` oferece integração perfeita com os widgets do Flutter, permitindo a criação de UIs reativas que se atualizam automaticamente quando os dados no box mudam, usando o `ValueListenableBuilder`.

ValueListenableBuilder(
  valueListenable: Hive.box('users').listenable(),
  builder: (context, box, _) {
    // Este builder será re-executado sempre que
    // o box 'users' for modificado.
    var user = box.get('currentUser');
    if (user == null) {
        return Text('Nenhum usuário logado.');
    }
    return Text('Usuário: ${user.name}');
  },
);

Comparação com SQLite

Documentação oficial

Hive

Simples, extremamente rápido, ideal para armazenamento de chave/valor e objetos Dart serializados. Perfeito para apps que não precisam de relações complexas.

SQLite (via `sqflite`)

Banco de dados relacional robusto. Melhor para dados complexos que exigem queries, junções (`JOINs`) e transações ACID.

Casos de Uso

Documentação oficial
  • Configurações do usuário: Salvar preferências como tema (claro/escuro), idioma, etc.
  • Cache local: Armazenar temporariamente dados vindos de uma API para uso offline e carregamento mais rápido.
  • Persistência de listas: Guardar listas de tarefas, notas, ou itens de um carrinho de compras.
  • Aplicativos offline-first: Essencial para apps que devem funcionar integralmente sem internet.

Boas Práticas

Documentação oficial
  • Fechar Boxes: Sempre feche os boxes que não estão mais em uso para liberar memória (`Hive.close()` ou `box.close()`).
  • `typeId` únicos: Garanta que cada `TypeAdapter` registrado tenha um `typeId` único em toda a aplicação.
  • Evite dados grandes: O Hive é otimizado para dados pequenos e médios. Evite armazenar arquivos grandes diretamente; prefira salvar o caminho do arquivo.
