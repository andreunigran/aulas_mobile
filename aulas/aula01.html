Explorando a Linguagem Dart

Uma introdução interativa à linguagem por trás do Flutter.

O que é e Como Funciona?

Esta seção apresenta o Dart, uma linguagem de programação versátil criada pelo Google. Aqui você entenderá seu propósito principal, sua otimização para interfaces de usuário e, crucialmente, os dois modos de compilação que garantem tanto um desenvolvimento ágil quanto uma performance excepcional em produção.

⚡ Compilação JIT (Just-In-Time)

Usada durante o desenvolvimento, a compilação JIT permite o famoso recurso **"Hot Reload"**. As alterações no código são aplicadas quase instantaneamente na aplicação em execução, sem a necessidade de reiniciar. Isso acelera drasticamente o ciclo de testes e a criação de interfaces.

🚀 Compilação AOT (Ahead-Of-Time)

Quando a aplicação está pronta para ser publicada, o código Dart é compilado AOT para código de máquina nativo (ARM/x64). Isso resulta em uma inicialização muito mais rápida e um desempenho consistentemente alto, pois a aplicação se comunica diretamente com o sistema operacional.

Histórico do Dart

2011: O Início

O Dart foi revelado pela primeira vez pelo Google em 2011. Seu objetivo inicial era ambicioso: ser um substituto estruturado e escalável para o JavaScript no desenvolvimento web.

2015: A Parceria com o Flutter

A trajetória do Dart mudou completamente com o surgimento do projeto Flutter, que escolheu o Dart por sua performance e produtividade, redefinindo o foco da linguagem para a criação de interfaces de usuário (UI).

Hoje: Uma Linguagem Multiplataforma

Atualmente, o Dart é a base do Flutter, impulsionando milhões de aplicações para mobile, web, desktop e sistemas embarcados, e continua a evoluir com recursos modernos como segurança de nulos.

Instalação do Dart SDK

Nota Importante sobre o Flutter

Se você planeja desenvolver com **Flutter**, não é necessário instalar o Dart SDK separadamente. O **Flutter SDK já inclui uma versão completa do Dart SDK**.

Verificando a Instalação

Após a instalação (seja via Flutter ou diretamente), abra um novo terminal e execute o seguinte comando para confirmar que o Dart foi instalado corretamente:

dart --version
Para outras opções, consulte a documentação oficial.

Tipos de Dados Fundamentais

Conversão de Tipos

String para Números

Use os métodos `parse()` ou `tryParse()` (para conversão segura, que retorna `null` em caso de erro).

var um = int.parse('1');
var erro = int.tryParse('abc'); // Retorna null

Números para String

Todo objeto em Dart tem um método `.toString()`.

String strNumero = 42.toString(); // '42'
String strDouble = 3.14159.toStringAsFixed(2); // '3.14'

Controle de Fluxo

Estruturas Condicionais

Permitem executar blocos de código diferentes com base em uma condição. As principais são `if/else` e `switch`.

int nota = 85;
if (nota >= 70) {
  print('Aprovado');
} else {
  print('Reprovado');
}

Estruturas de Repetição (Loops)

Permitem executar um bloco de código múltiplas vezes. As mais comuns são `for` (clássico e `for-in`) e `while`.

var frutas = ['Maçã', 'Banana', 'Laranja'];
for (var fruta in frutas) {
  print('Eu gosto de $fruta');
}

Imports e Entrada do Usuário

Aviso de Compatibilidade

A biblioteca dart:io, usada para ler a entrada do usuário (stdin), não funciona no DartPad. O código desta seção deve ser executado localmente em sua máquina.

Imports

A declaração `import` permite que você use código de outras bibliotecas. Para ler a entrada do usuário no console, por exemplo, precisamos da biblioteca `dart:io`.

import 'dart:io';

Lendo a Entrada do Usuário (stdin)

O método `stdin.readLineSync()` pausa a execução do programa e espera o usuário digitar uma linha e pressionar Enter.

stdout.write('Qual é o seu nome? ');
String? nome = stdin.readLineSync();
print('Olá, $nome!');

Orientação a Objetos em Dart

Classes e Objetos

Uma **classe** é um "molde" para criar **objetos**. Ela define propriedades (variáveis) e comportamentos (métodos). Um objeto é uma instância de uma classe.

Herança

A **herança** (`extends`) permite que uma classe (filha) herde propriedades e métodos de outra classe (pai), promovendo a reutilização de código.

Mixins

**Mixins** (`with`) são uma forma de reutilizar o código de uma classe em várias hierarquias de classes diferentes, sem usar herança. É como "misturar" funcionalidades.
