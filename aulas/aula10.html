Guia de Navegação em Flutter

Entendendo e implementando a transição entre telas.

Introdução à Navegação

O Que é Navegação em Flutter?

Flutter é um framework de UI da Google que permite criar aplicativos nativos com uma única base de código. Ele fornece uma rica variedade de widgets e ferramentas para implementar a transição entre telas de forma intuitiva e eficiente.

O Modelo de Pilha de Rotas

A navegação é gerenciada por uma **pilha de rotas**. Uma rota é, essencialmente, uma tela ou uma página no seu aplicativo. A pilha de rotas funciona de forma semelhante a uma pilha de pratos: você empurra (`push`) uma nova rota para o topo da pilha quando navega para uma nova tela, e remove (`pop`) a rota do topo quando volta para a tela anterior.

Tipos de Navegação

Navegação Imperativa (ou Anônima)

É a forma mais básica e comum de navegação. Utiliza `Navigator.push()` para adicionar uma nova rota à pilha e `Navigator.pop()` para remover a rota atual. É ideal para fluxos simples e diretos, onde as rotas não precisam ser acessadas de múltiplos locais.

Navegação Nomeada

Permite a navegação usando nomes de rotas (Strings, ex: `'/details'`). Você define todas as rotas em um mapa centralizado no `MaterialApp` e navega usando `Navigator.pushNamed()`. É excelente para organizar a navegação em apps maiores e evitar a duplicação de código.

Navegação com Argumentos

Frequentemente, você precisa passar dados entre telas (como o ID de um produto). O Flutter permite isso através de argumentos, que podem ser enviados ao navegar para uma nova rota e recuperados na tela de destino.

Navegação Imperativa: `push` e `pop`

Empurrando uma Nova Tela (`push`)

Para ir para uma nova tela, usamos `Navigator.push()`. Ele requer o `context` e uma `Route`, que geralmente é um `MaterialPageRoute` envolvendo o widget da nova tela.

Voltando para a Tela Anterior (`pop`)

Para voltar, usamos `Navigator.pop()`. O Flutter adiciona automaticamente um botão de "voltar" na `AppBar` que já faz isso, mas você pode chamar esse método de qualquer lugar.

// Tela 1 (Home)
ElevatedButton(
  child: Text('Ir para Tela 2'),
  onPressed: () {
    Navigator.push(
      context,
      MaterialPageRoute(builder: (context) => Tela2()),
    );
  },
);

// Tela 2
ElevatedButton(
  child: Text('Voltar para Tela 1'),
  onPressed: () {
    Navigator.pop(context);
  },
);

Navegação Nomeada

1. Definindo as Rotas

No seu `MaterialApp`, defina a propriedade `initialRoute` (a rota inicial) e o mapa `routes` com os nomes e os widgets correspondentes.

MaterialApp(
  initialRoute: '/', // Substitui a propriedade `home`
  routes: {
    '/': (context) => TelaHome(),
    '/detalhes': (context) => TelaDetalhes(),
  },
);

2. Navegando para a Rota

Use `Navigator.pushNamed()` e passe o nome da rota que você deseja abrir.

ElevatedButton(
  child: Text('Ver Detalhes'),
  onPressed: () {
    Navigator.pushNamed(context, '/detalhes');
  },
);

Passando Argumentos entre Telas

1. Enviando os Argumentos

Ao usar `pushNamed`, passe os dados que deseja enviar através do parâmetro `arguments`.

Navigator.pushNamed(
  context,
  '/detalhes',
  arguments: 'Olá da Tela Home!',
);

2. Recebendo os Argumentos

Na tela de destino, use `ModalRoute.of(context)!.settings.arguments` para extrair os dados. É importante fazer o cast para o tipo de dado correto.

class TelaDetalhes extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    // Extrai os argumentos
    final String mensagem = ModalRoute.of(context)!.settings.arguments as String;

    return Scaffold(
      appBar: AppBar(title: Text('Detalhes')),
      body: Center(
        child: Text(mensagem),
      ),
    );
  }
}

Exercício Prático

Objetivo

Crie um aplicativo simples com duas telas usando rotas nomeadas:

  1. Tela Home: Deve ter um botão "Ver Detalhes".
  2. Tela Detalhes: Deve exibir uma mensagem recebida da Tela Home.
  3. Ao clicar no botão na Tela Home, navegue para a Tela Detalhes e passe uma `String` como argumento.
  4. A Tela Detalhes deve exibir a `String` que recebeu.
