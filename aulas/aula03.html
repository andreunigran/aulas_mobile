Estrutura do App Flutter e Widgets Básicos

Entendendo a estrutura de um projeto, os principais widgets e como desenvolver uma interface básica.

Objetivos da Aula

  • Os principais widgets para criar interfaces.
  • Como desenvolver uma UI básica com interação.
  • Entregar uma interface funcional como exercício individual.

Estrutura de um Projeto Flutter

Ao criar um app com `flutter create`, a estrutura de pastas e arquivos principal é gerada para organizar seu projeto.

Principais Pastas e Arquivos

  • `lib/`: A pasta mais importante. Todo o seu código Dart ficará aqui. O ponto de entrada da sua aplicação é o arquivo `lib/main.dart`.
  • `pubspec.yaml`: O arquivo de configuração do projeto. Aqui você gerencia as dependências (pacotes externos), fontes, imagens e outras configurações.
  • `android/` e `ios/`: Contêm os projetos nativos de cada plataforma. Você raramente precisará editar o código aqui.

Ponto de Entrada: `main()` e `runApp()`

A execução de um app Flutter sempre começa na função `main()`, que por sua vez chama `runApp()` para inicializar e carregar o widget raiz da sua aplicação.

void main() {
  runApp(MyApp()); // MyApp é o widget raiz
}

Stateless vs. Stateful Widgets

A escolha entre `StatelessWidget` e `StatefulWidget` é fundamental e depende se a sua interface precisa mudar dinamicamente.

StatelessWidget (Sem Estado)

Não possui estado interno que possa mudar. Uma vez construído, ele permanece o mesmo. Ideal para partes estáticas da UI, como um ícone, um título ou um texto fixo.

StatefulWidget (Com Estado)

Possui um estado interno que pode ser alterado. Quando o estado muda (usando o método `setState()`), o widget se reconstrói para refletir a nova informação. Ideal para UIs interativas, como um contador, um formulário ou um checkbox.

Widgets Básicos e Layouts

Flutter oferece uma vasta biblioteca de widgets para construir qualquer interface. Aqui estão alguns dos mais essenciais.

Widgets Essenciais

  • Scaffold: Fornece a estrutura visual básica da página (com `appBar`, `body`, etc.).
  • Text: Exibe um texto simples.
  • Image: Exibe uma imagem, seja local (`.asset`) ou da internet (`.network`).
  • Container: Um "bloco" que pode ser estilizado com cor, borda, padding, etc.
  • ElevatedButton: Um botão padrão com elevação.

Layout com `Column` e `Row`

Para organizar widgets, usamos `Column` (para alinhar verticalmente) e `Row` (para alinhar horizontalmente).

// Exemplo de Column
Column(
  mainAxisAlignment: MainAxisAlignment.center, // Alinha no centro vertical
  children: [
    Text("Bem-vindo!"),
    ElevatedButton(onPressed: () {}, child: Text("Clique")),
  ],
)

Exemplos de Código

Exemplo 1: StatelessWidget

import 'package:flutter/material.dart';

void main() => runApp(MyStatelessApp());

class MyStatelessApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: Text('App Stateless')),
        body: Center(
          child: Text('UI Estática'),
        ),
      ),
    );
  }
}

Exemplo 2: StatefulWidget

import 'package:flutter/material.dart';

void main() => runApp(MyStatefulApp());

class MyStatefulApp extends StatefulWidget {
  @override
  _MyStatefulAppState createState() => _MyStatefulAppState();
}

class _MyStatefulAppState extends State<MyStatefulApp> {
  String texto = 'Olá!';

  void mudarTexto() {
    setState(() {
      texto = 'Você clicou!';
    });
  }

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: Text('App Stateful')),
        body: Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              Text(texto),
              ElevatedButton(
                onPressed: mudarTexto,
                child: Text('Clique aqui'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

Exercício de Entrega

Objetivo

Crie uma tela com os seguintes elementos:

  1. Uma `AppBar` com um título à sua escolha.
  2. Uma imagem (pode ser da internet com `Image.network`).
  3. Um `Text` centralizado.
  4. Dois botões (`ElevatedButton`):
    • - O primeiro botão deve alterar o texto da tela usando `setState()`.
    • - O segundo botão deve mostrar um `SnackBar`.

Critérios de Avaliação

  • Uso correto dos widgets solicitados.
  • Organização e indentação do código.
  • Uso de pelo menos um `StatefulWidget` para gerenciar o estado do texto.

Referências e Próximos Passos

Dúvidas Frequentes

  • Por que usar `StatefulWidget`? Para permitir que a UI reaja a eventos e mude dinamicamente.
  • Posso usar imagens da internet? Sim, com `Image.network('URL')`.
  • O botão não muda o texto, por quê? Verifique se você está chamando `setState()` dentro da função `onPressed`.
