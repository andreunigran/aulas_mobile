Formulários e Validação no Flutter

Aprendendo a criar formulários, capturar dados e validar antes de salvar ou enviar.

1 / 1

O que são Formulários no Flutter?

Formulários são estruturas essenciais para coletar informações do usuário em qualquer aplicativo, seja para cadastros, login, filtros ou configurações. Flutter oferece um conjunto robusto de widgets para facilitar a criação e o gerenciamento de formulários.

Por que Validar Dados?

  • Evitar erros: Garante que campos obrigatórios não fiquem vazios ou com formatos incorretos (ex: email inválido).
  • Melhorar a Experiência do Usuário (UX): Fornece feedback claro e imediato sobre os dados inseridos.
  • Garantir Segurança: Previne o envio de dados inválidos ou maliciosos para o backend da sua aplicação.

O Widget `TextField`

O `TextField` é o widget fundamental para a entrada de texto. Ele é ideal para capturas simples de dados onde a validação integrada não é uma prioridade.

Exemplo de `TextField`

TextEditingController

O `TextEditingController` é um objeto que permite controlar o texto de um `TextField` ou `TextFormField`, tanto para ler quanto para modificar seu conteúdo programaticamente.

Uso Básico

É crucial criar o controller e, mais importante, liberá-lo no método `dispose` para evitar vazamentos de memória.

// 1. Crie um controller para armazenar o texto
final _controller = TextEditingController();

@override
void dispose() {
  // 2. Libere a memória do controller quando a tela for fechada
  _controller.dispose();
  super.dispose();
}

Ações Comuns

  • Ler o valor: `_controller.text`
  • Alterar o valor: `_controller.text = "Novo valor";`
  • Limpar o campo: `_controller.clear();`

Formulários com `Form` e `TextFormField`

Para formulários completos com validação, a combinação dos widgets `Form` e `TextFormField` é a abordagem recomendada.

TextField vs. TextFormField

Enquanto o `TextField` é um campo de texto simples, o `TextFormField` é uma versão mais robusta que se integra a um widget `Form` e possui uma propriedade `validator` para validação embutida.

O Widget `Form` e a `GlobalKey`

O widget `Form` atua como um container que agrupa e gerencia vários campos de formulário. Ele é controlado por uma `GlobalKey`, que funciona como um "controle remoto" para validar, salvar ou limpar todos os campos de uma só vez.

// 1. Crie uma chave global para o formulário
final _formKey = GlobalKey<FormState>();

// 2. Associe a chave ao widget Form
Form(
  key: _formKey,
  child: Column(children: [
    // ... Seus TextFormField aqui
  ]),
);

// 3. Use a chave para validar o formulário
if (_formKey.currentState!.validate()) {
  // Se todos os campos forem válidos, execute esta ação
}

Validação com `TextFormField`

A propriedade `validator` recebe uma função que retorna uma `String` com a mensagem de erro se a validação falhar, ou `null` se o valor for válido.

TextFormField(
  decoration: InputDecoration(labelText: 'Nome'),
  validator: (value) { // Função de validação
    if (value == null || value.isEmpty) { // Se o valor for nulo ou vazio
      return 'Por favor, digite seu nome'; // Retorna a mensagem de erro
    }
    return null; // Retorna null se for válido
  },
);

Exemplo Completo de Formulário

import 'package:flutter/material.dart';

void main() => runApp(MyApp());

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(home: FormExample());
  }
}

class FormExample extends StatefulWidget {
  @override
  _FormExampleState createState() => _FormExampleState();
}

class _FormExampleState extends State<FormExample> {
  // Chave para identificar e controlar o formulário.
  final _formKey = GlobalKey<FormState>();
  // Controlador para ler o valor do campo de texto.
  final _nameController = TextEditingController();

  @override
  void dispose() {
    // Libera os recursos do controller para evitar vazamentos de memória.
    _nameController.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Formulário Flutter')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Form(
          key: _formKey, // Associa a chave ao formulário.
          child: Column(
            children: [
              TextFormField(
                controller: _nameController,
                decoration: InputDecoration(labelText: 'Nome'),
                validator: (value) {
                  if (value == null || value.isEmpty) {
                    return 'Digite seu nome';
                  }
                  return null;
                },
              ),
              SizedBox(height: 20), // Apenas um espaço vertical.
              ElevatedButton(
                onPressed: () {
                  // Verifica se o formulário é válido.
                  if (_formKey.currentState!.validate()) {
                    // Se for válido, exibe um SnackBar com o nome.
                    ScaffoldMessenger.of(context).showSnackBar(
                      SnackBar(content: Text(
                        'Nome válido: ${_nameController.text}'
                      )),
                    );
                  }
                },
                child: Text('Enviar'),
              )
            ],
          ),
        ),
      ),
    );
  }
}

Boas Práticas

  • Sempre use um `Form` para agrupar campos relacionados que precisam ser validados em conjunto.
  • Lembre-se de chamar `dispose()` nos seus `TextEditingController` para liberar memória.
  • Crie funções de validação reutilizáveis para lógicas complexas (ex: validar email, CPF).
  • Forneça mensagens de erro claras e curtas para o usuário.
  • Considere usar `autovalidateMode` para dar feedback ao usuário em tempo real, enquanto ele digita.
