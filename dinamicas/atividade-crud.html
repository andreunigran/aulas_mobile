Guia: App de Cadastro de Contatos no Flutter

Um tutorial passo a passo para criar um formulário com validação, listagem e exclusão.

Objetivo do Tutorial

Documentação oficial

Este guia apresenta um passo a passo para montar uma aplicação Flutter com um formulário de cadastro (nome e telefone), validação de dados, armazenamento em memória e listagem dos contatos cadastrados, tudo na mesma tela. Ao final, adicionaremos a funcionalidade de exclusão, consolidando os principais conceitos de manipulação de estado e listas interativas.

Passo 1: Criar a Classe `Contato`

Documentação oficial

O primeiro passo é definir a estrutura de dados que representará cada contato. Criamos uma classe simples chamada `Contato` que conterá o nome e o telefone. O uso de `final` garante que, uma vez criado, um objeto `Contato` não poderá ser alterado (imutabilidade).

// Define a estrutura de um contato
class Contato {
  final String nome;
  final String telefone;

  // Construtor com parâmetros nomeados e obrigatórios
  Contato({required this.nome, required this.telefone});
}

Passo 2: Criar a Classe `Dados`

Documentação oficial

Para gerenciar nossa lista de contatos em memória, criamos uma classe `Dados`. Ela encapsula a lista, tornando o código mais organizado. O `_` antes de `_contatos` torna a lista privada, e o `getter` `contatos` expõe uma versão somente leitura para o resto do app.

// Classe para gerenciar a lista de contatos em memória
class Dados {
  // Lista privada para armazenar os contatos
  final List<Contato> _contatos = [];

  // Getter público para acessar a lista
  List<Contato> get contatos => _contatos;

  // Método para adicionar um novo contato
  void adicionarContato(Contato contato) {
    _contatos.add(contato);
  }

  // Método para remover um contato pelo índice
   void removerContato(int index) {
    _contatos.removeAt(index);
  }
}

Documentação oficial

Finalmente, para rodar a aplicação, modificamos o arquivo `lib/main.dart`. A função `main` chama `runApp` com o `MaterialApp` como widget raiz, que por sua vez define nossa `TelaContatos` como a tela inicial (`home`).

Passo 5: Adicionar Exclusão

Documentação oficial

Para permitir a exclusão de contatos, envolvemos nosso `ListTile` com o widget `Dismissible`. Ele permite que o usuário arraste o item para o lado para acionar uma ação, como remover o contato da lista. Também adicionamos um `IconButton` como uma alternativa de exclusão.

// Dentro do ListView.builder
return Dismissible(
  key: ValueKey(contato), // Chave única para o widget
  background: Container( /* ... fundo vermelho ... */ ),
  onDismissed: (direction) => _removerContato(index),
  child: ListTile(
    // ... title e subtitle ...

      icon: const Icon(Icons.delete, color: Colors.red),
      onPressed: () => _removerContato(index),

Código Completo

Abaixo está o código completo do arquivo `lib/main.dart` com todas as funcionalidades implementadas: modelo de dados, gerenciador de estado, formulário com validação, e listagem com adição e remoção de contatos.

import 'package:flutter/material.dart';

// Passo 1: Modelo de Dados
class Contato {
  String nome;
  String telefone;
  Contato({required this.nome, required this.telefone});
}

// Passo 2: Gerenciador de Estado
class Dados {
  final List<Contato> _contatos = [];
  List<Contato> get contatos => _contatos;
  void adicionarContato(Contato contato) => _contatos.add(contato);
  void removerContato(int index) => _contatos.removeAt(index);
  void editarContato(int index, Contato novoContato) => _contatos[index] = novoContato;
}

// Passo 4: Função Principal
void main() {
  runApp(const MaterialApp(
    home: TelaContatos(),
    debugShowCheckedModeBanner: false,
  ));
}

// Passo 3: Tela Principal
class TelaContatos extends StatefulWidget {
  const TelaContatos({super.key});
  @override
  State<TelaContatos> createState() => _TelaContatosState();
}

class _TelaContatosState extends State<TelaContatos> {
  final _formKey = GlobalKey<FormState>();
  final _nomeController = TextEditingController();
  final _telefoneController = TextEditingController();
  final Dados _dados = Dados();

  void _salvarContato() {
    if (_formKey.currentState!.validate()) {
      setState(() {
        _dados.adicionarContato(
          Contato(nome: _nomeController.text, telefone: _telefoneController.text),
        );
        _nomeController.clear();
        _telefoneController.clear();
        FocusScope.of(context).unfocus(); // Esconde o teclado
      });
    }
  }

  void _removerContato(int index) {
    setState(() {
      _dados.removerContato(index);
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text("Cadastro de Contatos")),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          children: [
            Form(
              key: _formKey,
              child: Column(
                children: [
                  TextFormField(
                    controller: _nomeController,
                    decoration: const InputDecoration(labelText: "Nome"),
                    validator: (valor) {
                      if (valor == null || valor.trim().isEmpty) return "Digite um nome válido";
                      return null;
                    },
                  ),
                  TextFormField(
                    controller: _telefoneController,
                    decoration: const InputDecoration(labelText: "Telefone"),
                    keyboardType: TextInputType.phone,
                    validator: (valor) {
                      if (valor == null || valor.trim().isEmpty) return "Digite um telefone válido";
                      if (!RegExp(r'^\d{8,15}$').hasMatch(valor)) return "Telefone inválido";
                      return null;
                    },
                  ),
                  const SizedBox(height: 12),
                  ElevatedButton(
                    onPressed: _salvarContato,
                    child: const Text("Adicionar Contato"),
                  ),
                ],
              ),
            ),
            const SizedBox(height: 20),
            const Text("Lista de Contatos", style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold)),
            const Divider(),
            Expanded(
              child: ListView.builder(
                itemCount: _dados.contatos.length,
                itemBuilder: (context, index) {
                  final contato = _dados.contatos[index];
                  return Dismissible(
                    key: ValueKey(contato),
                    background: Container(
                      color: Colors.red,
                      alignment: Alignment.centerLeft,
                      padding: const EdgeInsets.only(left: 20),
                      child: const Icon(Icons.delete, color: Colors.white),
                    ),
                    secondaryBackground: Container(
                      color: Colors.red,
                      alignment: Alignment.centerRight,
                      padding: const EdgeInsets.only(right: 20),
                      child: const Icon(Icons.delete, color: Colors.white),
                    ),
                    onDismissed: (direction) => _removerContato(index),
                    child: ListTile(
                      leading: const Icon(Icons.person),
                      title: Text(contato.nome),
                      subtitle: Text(contato.telefone),
                      trailing: IconButton(
                        icon: const Icon(Icons.delete, color: Colors.red),
                        onPressed: () => _removerContato(index),
                      ),
                    ),
                  );
                },
              ),
            ),
          ],
        ),
      ),
    );
  }
}

Desafio: Editar Contatos

Documentação oficial

Agora que você já sabe adicionar e remover contatos, o próximo passo é implementar a funcionalidade de edição. Este é um excelente exercício para aprofundar seus conhecimentos em manipulação de estado e interação com o usuário.

Objetivo

Modifique a aplicação para permitir que o usuário edite o nome e o telefone de um contato existente na lista.

Dicas para Implementação

  • Botão de Edição: Adicione um `IconButton` com um ícone de edição (ex: `Icons.edit`) ao `ListTile`, ao lado do ícone de exclusão.
  • Diálogo de Edição: Ao clicar no botão de edição, prencha o formulário pré-preenchido com os dados do contato selecionado.
  • Lógica de Atualização: Crie um novo método na classe `Dados` e no `State` da tela para atualizar o contato na lista com os novos valores. Lembre-se de chamar `setState()` para que a UI reflita a mudança.
